# AI Energy Life Assistant · AI 能源生活助手

> 独立产品设计项目（AI 产品经理方向）—— 一个整合家庭储能、语音交互与智能家居的 AI 能源生活助手概念设计。

**一句话定位：** 这不是新的设备遥控器，而是「家庭能源运营助手」—— 用 AI 把「发现浪费 → 安全执行 → 验证省钱」做成一条可信、可闭环、可量化的体验。

---

## 🎯 项目亮点

- **完整的产品闭环**：数据接入 → AI 预测 → 约束优化 → 用户授权执行 → 省钱验证，而非停留在「设备控制」。
- **可量化的价值主张**：用反事实基线把「AI 很智能」落成「本月已验证净节省 $X」，区分保守/中等/乐观三档口径。
- **严谨的 AI 协作方法论**：20+ 轮红队质疑，主动击穿「语音是护城河」「游戏化拉留存」「免费 App 带货」等表面完整但证据不足的假设。
- **可直接体验的高保真原型**：单文件 HTML，覆盖首次设置、行动首页、能源计划、设备、个人报告与停电应急全流程。

## 🧭 核心内容速览

### 四大场景

1. **智慧用电优化**（核心高频）—— 预测未来 24h 光伏/负载/电价，生成充放电与设备运行计划。
2. **露营能源管家**（移动/增长）—— 按设备清单、天气与真实电池健康计算续航，辅助选型。
3. **应急备电响应**（低频高价值）—— 停电时预测续航、给出关键负载方案（硬件负责物理切换）。
4. **语音能源管家**（可选入口）—— 自然语言查询与确认，定位为增强而非护城河。

### 关键产品决策

- **用户分层**：L1 账单评估 / L2 能源连接 / L3 能源托管，不让「没有储能设备」成为流失点。
- **首页定位**：从「数据看板」改为「今日能源行动中心」—— 回答「今天该做什么、能省多少」。
- **北极星指标**：单户月均**已验证净节省**，而非 DAU。
- **商业化**：先做内嵌 MVP 与对照实验验证因果增量，再按增量贡献毛利与完整 TCO 决定是否扩张。

## 🛠️ 技术边界（重要）

- 时间序列模型做预测，确定性约束优化器做计划，**LLM 只负责解释与对话**。
- 停电检测、并离网切换、SOC/温度/功率硬限制等**电气安全始终由认证固件/硬件负责**，云端 AI 不进入物理切换关键路径。
